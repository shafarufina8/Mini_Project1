# Mini_Project_1_Shafa Aurellia Rufina Maharani

Nama: Shafa Aurellia Rufina Maharani
NIM: 001

Program ini dirancang sebagai sistem pengelolaan data ekstrakurikuler sekolah digital yang secara otomatis menyiapkan data awal seperti nama ekskul, hari, dan pembina, lalu menjalankan perulangan (looping) menu utama agar pengguna dapat melihat seluruh daftar ekskul, menambah data baru, mengubah data yang sudah ada, atau menghapus ekskul dengan adanya validasi input untuk mencegah error ketika salah memasukkan nomor/menu, hingga akhirnya program dihentikan secara saat pengguna memilih menu keluar.
